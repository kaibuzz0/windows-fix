## 📖 Detailed Usage

### STEP 1: DEBLOAT (Remove Junk)

**Option A - Quick (Recommended for most users):**
```batch
1-Debloat\Ultimate-Debloat.bat
:: Select [1] Quick Debloat
```

Removes: Xbox, Skype, Solitaire, News, Weather, Tips, etc. (Safe)

**Option B - Full:**
```batch
1-Debloat\Ultimate-Debloat.bat
:: Select [2] Full Debloat
```

Removes: Above + Photos, Maps, Camera, Mail, Calendar, etc.

**Option C - Nuclear (Advanced only):**
```batch
1-Debloat\Ultimate-Debloat.bat
:: Select [3] Nuclear Option
```

Removes: Above + Store, Edge (some), basically everything. ⚠️ Dangerous

### STEP 2: OPTIMIZE (Make Fast)

**For Gaming:**
```batch
2-Performance\Performance-Optimizer.bat
:: Select [1] Gaming Mode
```

- Disables Game DVR
- Enables Game Mode
- Low latency network
- High performance power plan
- Disables mouse acceleration
- Optimizes services

**For Productivity:**
```batch
2-Performance\Performance-Optimizer.bat
:: Select [2] Workstation Mode
```

- Balanced visual effects
- Fast app launching
- Good multitasking
- Keeps search for file finding

### STEP 3: REPAIR (If Broken)

```batch
3-Repair\Windows-Repair-Suite.bat
:: Select [9] All-In-One Repair
```

Runs:
1. SFC /scannow
2. DISM ScanHealth
3. DISM RestoreHealth
4. Windows Update repair
5. System cleanup

Takes 20-45 minutes, fixes most Windows issues.

### STEP 4: PRIVACY (Stop Spying)

```batch
1-Debloat\Ultimate-Debloat.bat
:: Select [4] Privacy Hardening
```

Disables:
- All telemetry
- Data collection
- Location tracking
- Activity history
- Cortana
- Advertising ID
- Feedback
- Suggested content

## 🔍 Troubleshooting

### "Script won't run"
- **Fix:** Right-click → Run as Administrator

### "Access denied"
- **Fix:** Disable Windows Defender real-time protection temporarily

### "Some apps still there"
- **Fix:** Run the specific app remover in `1-Debloat\`

### "Windows Update broken"
- **Fix:** Run `3-Repair\Windows-Update-Fix.bat`

### "No internet after debloat"
- **Fix:** Run `3-Repair\Network-Reset.bat`

### "Want apps back"
- **Fix:** Run `1-Debloat\Ultimate-Debloat.bat` → Select [7] Restore Defaults
